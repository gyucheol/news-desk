## 3. 첨부 사진 0번~0-6번

1. 7장 모두 v3 때 보내 주신 29장 중 하나와 파일이 같습니다(바이트 단위로 같은 파일, md5 비교). 그래서 v3의 워터마크를 지운 판(work/owner_v3/NN.png)을 그대로 썼습니다.
2. 두 번째 메시지의 2장은 보낸 순서대로 0-5번 = 30번(탁자 위의 꺼진 휴대폰), 0-6번 = 9번(프로필 사진을 보는 사람)입니다. 내용도 '주도권을 내가 쥐세요', '프로필 사진을 확대해 보는 대신'과 맞습니다.
3. 첫 메시지의 5장은 22번, 3번, 2번, 28번, 7번 순서로 왔습니다. 이 순서를 그대로 0~0-4번으로 읽으면 '지우가 … 카톡창을 들락날락하고'에 노키아 실험 학생(22번)이, '단순히 기분만 우울해지는 게 아니라'와 '이미 마음이 무겁게 가라앉았다면'에 간호사와 아이(28번)가 들어가 대사와 맞지 않습니다. 그래서 사진 내용과 대사로 정했습니다(추론, 유추: 각 사진이 v3에서 놓였던 대사와 새 대사의 뜻을 맞춰 봄). 결과는 보낸 순서를 거꾸로 읽은 것과 같습니다.
   - 0번 = 7번: 지하철에서 카톡을 보내는 지우 → '지우가 줄어들지 않는 숫자 1을 보며 / 밤새 카톡창을 들락날락하고'
   - 0-1번 = 28번: 간호사가 안은 아이(로라) → '어릴 적 로라의 마음속에서 …'
   - 0-2번 = 2번: 어둠 속에서 휴대폰을 쥔 사람 → '이런 분들은 연인과 연락이 원활하지 않을 때', '6시 30분에 보낸 카톡이 …'
   - 0-3번 = 3번: 침대 옆 바닥에 주저앉아 머리를 감싼 사람 → '단순히 기분만 우울해지는 게 아니라', '이미 마음이 무겁게 가라앉았다면'
   - 0-4번 = 22번: 휴대폰 옆에서 이마를 짚은 학생 → '왜 연락이 없지? / 나한테 마음이 식었나?'
4. 틀린 곳이 있으면 번호만 알려 주시면 바로 바꿉니다(build_spec_v4.py의 사진 번호만 바꾸면 됨).
