# 7월 카드 → '제목 + 한줄 요약' 변환 (서브 에이전트 공통 지시)

사용자는 뉴스 목록을 '뉴스 제목 + 한줄 요약'만 보여 주는 형식으로 바꾸려 합니다(번호 없음).
당신은 이미 사실 확인을 거친 7월 요약 카드 약 50장을 받아, 카드마다 제목 1개와 한줄 요약 1개를 만듭니다.
새 웹 조사는 하지 않습니다(카드에 든 사실만 씁니다). DB 저장도 하지 않습니다.

## 입력
/home/user/news-desk/work/oneliner/inNN.json — 카드 목록. 필드:
- headline, facts[]: 카드 본문(강조 표시는 지움). facts 끝의 [사실]·[추측] 등 꼬리표와 '채널 전언'·'채널에 따르면' 표시를 눈여겨보세요.
- check: 무엇을 확인했고 무엇을 확인하지 못했는지.
- verifyReport: 재확인 결과(verified=true, corrected=[고친 내용], unverified=[여전히 확인 못 한 내용]). 비어 있으면 재확인 기록 없음.
- published(한국 시간), channel, url, inds, dupOf.

## 한줄 요약 규칙 (사용자 지시 그대로)
- 구조: [주체]가 [핵심 행동, 핵심 변화]하면서 [어떤 대상에 어떤 영향이 생기는지]
- 이 한 줄만 읽어도 '누가 무엇을 했고, 그래서 무엇이 달라지는지' 알 수 있어야 합니다.
- 규모, 시점, 원인 중 이해에 꼭 필요한 정보 하나를 넣습니다(숫자 하나면 충분).
- 잘못된 예: 해양시추 업황 개선 기대
- 옳은 예: 석유회사들의 해양 개발 발주가 늘어나는 가운데 투입 가능한 시추선은 부족해, 새 계약의 시추선 임대료가 상승하고 있다
- 한 문장, '~다'로 끝맺음. 가능하면 100자 안팎, 길어도 130자 이내.
- '업황 개선 기대', '수혜 전망'처럼 대상과 이유가 빠진 표현 금지.
- 영향 부분은 카드 facts·tags에 근거가 있는 것만 씁니다. 카드에서 추론으로 표시된 영향이면 '~할 수 있다'처럼 단정하지 않습니다.
- 핵심 수치가 확인되지 않은 채널 주장이면(꼬리표·check·verifyReport.unverified로 판단) 그 수치를 빼고 쓰거나, 꼭 필요하면 문장 끝에 '(채널 전언)'을 붙입니다.
- 강조 기호({{ }}), 굵은 글씨, 번호를 쓰지 않습니다.

## 제목 규칙
- 신문 기사 제목처럼 짧게(대략 20~45자). 주체와 핵심 사건이 드러나야 합니다. 예: '도시바, AI 데이터센터용 HDD 생산능력 2배로…필리핀에 600억 엔 투자'
- 한줄 요약과 같은 문장을 반복하지 않습니다.

## 출력
/home/user/news-desk/work/oneliner/out/oNN.json — 입력 순서대로 배열:
[{"key": 카드 key, "title": 제목, "one": 한줄 요약, "date": published 앞 10자리, "channel": channel, "url": url, "inds": inds,
  "basis": "verified|partial|channel" (핵심 사실 확인 정도: 재확인·다른 매체로 확인=verified, 일부만=partial, 채널 주장 위주=channel),
  "note": "판단이 애매했던 점이 있으면 짧게, 없으면 빈칸"}]
- 카드가 관심 산업과 무관하거나 한 줄로 쓸 만한 사실이 없으면 one을 비우고 note에 이유를 적습니다(카드를 지어내서 채우지 마세요).

## 점검(끝내기 전 스스로)
python3 -c "import json;d=json.load(open('/home/user/news-desk/work/oneliner/out/oNN.json'));print(len(d), max(len(x['one']) for x in d), sum(1 for x in d if len(x['one'])>130))"
→ 입력 카드 수와 같고, 130자 초과가 0이어야 합니다.
