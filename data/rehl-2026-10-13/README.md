# 강조 다시 칠하기 (2026-10-13)

사용자 지시: 지금 강조는 예전 방식(제목 1~2곳, 한줄 2~4곳의 성긴 강조)이니, 사용자가 10월 4일 직접 표시해 정한 기준(tools/cardkit/GUIDE-short.md: 문장 뼈대를 칠해 강조만 이어 읽어도 뜻이 통하게, 50~65%)으로 다시 칠할 것.

- 대상: 안 읽은 뉴스 513건(계정 읽음 기록과 updatedAt으로 판정, targets.json). 제목·한줄 요약·더해진 내용·원문별 s, 상세·인사이트가 있는 2건(n-tg-0187, n-tg-0192)은 그 본문(소제목·출처 목록 제외)까지 2,561줄.
- 방식: 기존 {{ }}를 지우고 글자는 그대로 둔 채 강조만 새로 넣음. Haiku 서브 에이전트 10개(노력 max)가 묶음별로 작성 → check.py로 글자 불변·괄호 짝·꼬리표/링크 미포함 검사(문제 0) → 30% 미만 26줄은 메인이 직접 보충(fix_low.tsv) → apply.py로 바뀐 필드만 update(if_version), 50건씩 11번.
- 결과: 강조 비율 65%. 남은 경고는 제목(명사구라 90%대)과 인사이트 짧은 표지 등 192줄로 그대로 둠.
- updatedAt은 건드리지 않아 읽음 상태 변화 없음. 저장 뒤 DB를 다시 받아 513건 모두 의도한 값과 일치, 다른 문서 변화 없음 확인.
- 실행 순서(스크래치 폴더 기준): targets.py db/news reads.json → prep.py db/news → (에이전트) → check.py → apply.py. 입력·출력 파일과 DB 사본은 저장소에 두지 않음.
