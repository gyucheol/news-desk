# 강조 다시 표시하기 — 작업 지침

## 하는 일

투자 뉴스 대시보드의 문장에 강조 표시 `{{ … }}` 를 다시 넣습니다. 화면에서는 강조한 부분이 "회색 글씨 + 회색 바탕 + 굵게"로 보입니다.

사용자가 원하는 것은 하나입니다. **강조한 부분만 이어 읽어도 문장의 뜻이 통해야 합니다.** 사용자는 바쁠 때 강조한 부분만 훑어 읽습니다.

글자는 한 글자도 바꾸지 않습니다. 띄어쓰기, 문장부호, 숫자, 오타까지 그대로 두고 `{{` 와 `}}` 만 넣습니다.

## 사용자가 직접 표시한 예시 (이것이 기준입니다)

```
{{수출 중단 소식}}에 채널이 {{블룸버그}}와 {{대만 경제일보}}를 인용해 전했습니다.

{{셸}}이 {{루이지애나·텍사스·펜실베이니아의 미국 화학 시설 4곳}}을 팔려 하고, {{매각가}}는 {{최대 80억 달러}}로 거론된다고 FT가 보도했습니다

{{일본은행}}이 {{10월 1일 공개}}한 {{9월 회의}}(정책금리 1.0% → 1.25%) 의견 요약에서 {{다수 의견}}이 {{9월 인상에 이어 추가 인상이 필요}}하다고 봤습니다. 한 위원은 '{{물가}}가 {{위로 벗어나는 신호}}가 보이면 {{인상 속도를 높여야}} 한다', {{다른 위원}}은 '{{예상 밖 상황에 대응할 여지}}를 두려면 {{정책금리}}를 비교적 이른 시기에 {{대략적인 목표 수준에 가깝게 올리는 것}}이 {{바람직}}하다'고 했습니다. {{기조적 물가}}가 {{2%에 이르렀거나 가깝다}}는 의견도 여럿이었습니다(로이터).

{{대형 제조업 체감지수}}는 {{+24}}로 {{6월(+22)보다 올랐}}지만 {{시장 예상(+25)에는 못 미쳤}}고, {{대형 비제조업}}은 {{+35}}(6월 +37, 예상 +36)였습니다. {{기업들}}은 {{물가 상승률}}을 {{3년 뒤 2.6%}}, {{5년 뒤 2.5%}}로 봐 {{2% 목표}}를 {{오래 웃돌 것으로 예상}}했습니다. {{일본은행}}은 {{이 자료를 10월 회의의 성장·물가 전망에 반영}}합니다(로이터).
```

강조만 이어 읽어 보면 이렇게 됩니다. "셸 / 루이지애나·텍사스·펜실베이니아의 미국 화학 시설 4곳 / 매각가 / 최대 80억 달러". 조사와 어미가 없어도 무슨 일인지 알 수 있습니다. 이것이 목표입니다.

## 강조하는 것 — 문장의 뼈대

1. 누가·무엇이. 주어나 주제가 되는 이름과 명사구입니다. 예: 셸, 일본은행, 다수 의견, 대형 제조업 체감지수, 기조적 물가.
2. 무엇을·무엇에. 핵심 대상입니다. 꾸미는 말이 붙어 있으면 함께 한 덩어리로 묶습니다. 예: 루이지애나·텍사스·펜실베이니아의 미국 화학 시설 4곳, 물가 상승률, 2% 목표.
3. 수치. 숫자는 단위·방향·기준과 함께 한 덩어리로 묶습니다. 예: 최대 80억 달러, +24, 3년 뒤 2.6%, 6월(+22)보다 올랐.
4. 서술의 줄기. 무슨 일이 일어났는지, 어느 방향인지, 어떤 판단인지 알려 주는 말입니다. 예: 추가 인상이 필요, 인상 속도를 높여야, 못 미쳤, 바람직, 오래 웃돌 것으로 예상, 반영, 취소, 차단.
5. 뜻을 바꾸는 조건·원인·때. 예: 10월 1일 공개, 9월 회의, 위로 벗어나는 신호, 예상 밖 상황에 대응할 여지. 구체적인 날짜와 기간(9월 17일, 2027년 상반기, 3년 뒤)은 강조하고, 막연한 때(최근, 지난달, 앞서, 이번에)는 강조하지 않습니다.

## 강조하지 않는 것

1. 덩어리 바로 뒤의 조사. 은·는·이·가·을·를·에·에서·로·으로·와·과·도·만 따위는 `}}` 밖에 둡니다. 덩어리 안쪽에 낀 조사는 그대로 둡니다(예: `{{이 자료를 10월 회의의 성장·물가 전망에 반영}}합니다`).
2. 어미와 서술 꼬리. ~했습니다, ~합니다, ~입니다, ~됩니다, ~하다고 봤습니다, ~한다, ~지만, ~고, ~는 뜻입니다. 줄기만 강조하고 꼬리는 밖에 둡니다(예: `{{취소}}했습니다`, `{{반영}}합니다`, `{{올랐}}지만`, `{{필요}}하다고`).
3. 전달하는 틀. ~라고 FT가 보도했습니다, 채널이 … 인용해 전했습니다, ~라고 말했습니다, ~라고 밝혔습니다, ~는 의견도 여럿이었습니다. 다만 누가 말했는지가 그 문장의 내용이면 이름만 강조합니다(예시 1의 블룸버그, 대만 경제일보. 발언자 이름도 여기에 듭니다: `{{부이치치 ECB 부총재}}는 … 경고했습니다`).
4. 괄호 속 보충. (정책금리 1.0% → 1.25%), (6월 +37, 예상 +36), (로이터), (채널 전언), (전체의 약 76%) 같은 출처·환산·보조 수치·부연 설명입니다. 다만 이름에 바로 붙은 짧은 풀이나 약칭(대략 6자 이하)과 덩어리 한가운데에 낀 짧은 괄호는 덩어리와 함께 둡니다(예: `{{미국 원자력규제위원회(NRC)}}`, `{{폴리머(합성수지)}}`, `{{6월(+22)보다 올랐}}`).
5. 뜻이 가벼운 말. 흔한 주어(채널이, 한 위원은, 글쓴이는, 보도는, 기사는), 정도·태도 부사(비교적 이른 시기에, 예상대로, 사실상), 이어 주는 말(그러자, 다만, 반면, 한편, 또, 그래서), 가벼운 동사(있다, 하다, 되다, 보다, 봐, 두려면, 보이면, 꼽히며, 거론된다, 나왔다, 맺었다, 얻는다, 돌아간다), 홀로 선 형식 명사(것, 때, 모습, 구도, 사례, 뜻). 앞의 덩어리가 이미 뜻을 전하면 뒤따르는 가벼운 동사는 강조하지 않습니다(예: `{{20년간 연 50만 톤을 사는 계약}}을 맺었습니다`).
6. 머리말과 꼬리표. "이미 다룬 사건(…)의 새 내용입니다 —", "이득:", "왜 지금:", "시점:", "확인:", "채널(…):" 같은 머리말과 [사실]·[유추]·[귀납]·[연역]·[추측] 꼬리표는 강조하지 않습니다.

## 덩어리 만드는 법

- 한 덩어리는 보통 2~20자입니다. 30자를 넘기지 말고, 넘으면 조사나 쉼표에서 나눕니다.
- 문장 전체를 통째로 강조하지 않습니다. 대신 절마다(주어와 서술 한 쌍마다) 뼈대를 빠짐없이 짚습니다. 한 절에 덩어리가 하나도 없으면 그 절은 훑어 읽을 때 사라집니다.
- 덩어리는 공백으로 시작하거나 끝나지 않습니다. 쉼표·마침표·따옴표·가운뎃점 구분(·)은 덩어리 밖에 둡니다. 단, 이름 사이의 가운뎃점(엑슨모빌·라이온델바젤·아폴로)은 한 덩어리 안에 둡니다.
- 나열은 항목마다 따로 묶습니다. 예: `{{3년 뒤 2.6%}}, {{5년 뒤 2.5%}}`.
- 따옴표 속 인용문도 같은 규칙으로 안쪽을 나눠 강조합니다.
- 서술어는 어미 앞에서 끊습니다. `{{늘었}}습니다`, `{{막혔}}습니다`, `{{줄었}}고`, `{{꺼리}}고`. 끊으면 한 글자만 남거나 깔끔하게 끊기지 않는 낱말은 낱말째 강조합니다. 예: `{{같습니다}}`, `{{없습니다}}`, `{{큽니다}}`, `{{커져}}`, `{{이어집니다}}`, `{{막으면}}`. 어미 처리는 완벽하지 않아도 됩니다. 망설여지면 낱말째 묶고 넘어갑니다.
- 명사로만 이어지는 짧은 메모는 맨 끝의 가벼운 서술 명사(운영, 보유, 사용, 예정, 중)를 밖에 둡니다. 예: `{{LNG캐나다 지분 15%}} 보유`, `{{불가항력 연장}} 중`. 추진·수주·매각·합병처럼 사건을 나타내는 낱말은 강조합니다.
- 보도 매체가 "~가 보도했습니다"처럼 전달하는 틀의 주어일 뿐이면 매체 이름도 강조하지 않습니다. 주장하거나 행동한 당사자(기관, 장관, 회사, 분석 기관)는 강조합니다.
- 분량 감각: 강조한 글자가 전체의 절반에서 3분의 2쯤(대략 50~65%)입니다. 30%에 못 미치면 뼈대가 빠진 것이고, 80%를 넘으면 조사·어미·전달 표현·가벼운 말까지 넣은 것입니다.


## 작업 파일 형식

입력 파일은 두 줄이 한 묶음입니다. `@@` 로 시작하는 줄이 이름표이고(번호, 글의 종류, 대괄호 안은 이미 떼어 둔 머리말), 바로 다음 줄이 문장입니다. `## ` 로 시작하는 줄은 어느 카드인지 알려 주는 참고용입니다.

```
## news/n-tg-0094 | 중국 석유제품 수출 중단에 브렌트유 100달러 재돌파 — …
@@u01234 사실 [얼마나]
중국은 정유 능력이 세계 최대인데 가동률은 최대 75% 수준이고, 미국 정유 가동률은 97%입니다
```

출력 파일은 입력 파일과 줄 구성이 똑같아야 합니다. `##` 줄과 `@@` 줄은 그대로 옮기고, 문장 줄에만 `{{ }}` 를 넣습니다.

```
## news/n-tg-0094 | 중국 석유제품 수출 중단에 브렌트유 100달러 재돌파 — …
@@u01234 사실 [얼마나]
{{중국}}은 {{정유 능력}}이 {{세계 최대}}인데 {{가동률}}은 {{최대 75% 수준}}이고, {{미국 정유 가동률}}은 {{97%}}입니다
```

## 검사

파일 하나를 쓰면 바로 검사합니다.

```
python3 /home/claude/downturn-desk/hl/check.py /home/claude/downturn-desk/hl/work/in/p001.txt /home/claude/downturn-desk/hl/work/out/p001.txt
```

- `!` 로 시작하는 줄(PROBLEMS)은 반드시 0이 될 때까지 고칩니다. 글자가 바뀌었거나, 괄호 짝이 안 맞거나, 줄이 빠진 경우입니다.
- `~` 로 시작하는 줄(WARN)은 한 번 훑어보고 지침에 어긋나는 것만 고칩니다. "강조가 없습니다", "강조가 적음", "강조가 너무 많음"은 대부분 고쳐야 하고, 나머지는 지침에 맞으면 그대로 둡니다.

## 마지막으로 스스로 확인

문장마다 강조한 덩어리만 차례로 읽어 봅니다. 누가, 무엇을, 얼마나, 어떻게 됐는지가 떠오르면 된 것입니다. 숫자만 남거나, 주어가 빠졌거나, 방향(늘었는지 줄었는지)이 빠졌으면 덩어리를 더합니다.
