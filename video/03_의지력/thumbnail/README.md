# 03편 「퇴근 후 의지력」 썸네일 후보 (2026-10-31)

사용자 요청 "썸네일 후보군 3개"로 만든 시안입니다. 틀은 번아웃 편과 같은 「F의 연애」 틀(../../burnout/HANDOFF_VIDEO.md 18장)이고,
번아웃 편에서 사용자가 고른 '배경을 다 살린 판'으로 세 장을 만들었습니다. 그림에는 효과를 넣지 않았습니다.
시안 파일은 올리지 않았습니다(A, B는 사용자 AI 사진, C는 스톡 장면이 들어 있음).

- 주제 단어: "의지력"(이 편 이름 「퇴근 후 의지력」에서). 흰색, Noto Sans KR 800, 262px, 바닥선 y=679. 글자 높이 246px, 너비 723px, 윗선 y=458.
- A: 사용자 AI 사진 11번(침대에 누워 팔로 눈을 가린 사람, 바닥에 운동 가방). 글자 가운데 x=800(얼굴과 왼손을 피함).
  `thumb.py full 썸네일_A.jpg photos_final/P11.png --word 의지력 --word-cx 800`
- B: 사용자 AI 사진 47번(운동 가방 옆 소파에서 고개를 숙인 사람, 얼굴은 머리카락에 가림). 글자가 맞잡은 손을 덮지 않게 원본 (0,20)~(1120,650)만 써서
  사람을 오른쪽으로 옮기고 글자를 왼쪽(x=420)에 둠(손은 x=811~931, 글자 오른끝 x=781).
  `thumb.py full 썸네일_B.jpg photos_final/P47.png --word 의지력 --word-cx 420 --box 0,20,1120,650`
- C: Mixkit 25579 "Sad and desperate man lying on a sofa"의 5.5초(본편 st09와 같은 영상, 라이선스 Free, 2026-10-29 확인 v1 stock/items/lic_25579.json).
  팔로 눈을 가렸고 코와 입은 보입니다. 글자 가운데 x=880(주먹과 얼굴을 피함).
  `ffmpeg -ss 5.5 -i stock/full/25579.mp4 -frames:v 1 s25579_5.5.png` 다음 `thumb.py full 썸네일_C.jpg s25579_5.5.png --word 의지력 --word-cx 880`
- 비교용 한 장: `thumb.py preview 썸네일_비교.png 썸네일_A.jpg 썸네일_B.jpg 썸네일_C.jpg --labels A,B,C`(640px와 휴대폰 피드 크기 360px)
- 고르지 않은 그림: 47번을 그대로 쓰면 글자가 손을 덮고, 7번(엎드린 사람)과 스톡 25585(책상)도 글자가 손을 덮음. 5번은 얼굴이 보이고,
  스톡 25596(침대에 엎드림)은 바탕이 밝아 흰 글자가 잘 읽히지 않음.
- 업로드 때: A, B는 사진풍 AI 사진이라 '변경되거나 합성된 콘텐츠'를 '예'로 체크합니다(본편도 AI 사진이 있어 같은 표시).
