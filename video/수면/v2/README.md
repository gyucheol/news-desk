# 수면 편 영상 v2 기록 (2026-11-04)

v1(../v1/README.md)에서 두 가지를 바꾼 판입니다. 영상, 녹음, 사진은 올리지 않았습니다.

요청(2026-11-04)
- "밑의 대본의 녹음본이 약간 이상해서 다시 녹음했음. 밑의 대본의 부분만 151녹음본으로 바꿔줘."
  (바꿀 곳: '참가자들은 14일 동안 …'부터 '… 비슷한 수준까지 떨어졌습니다.'까지 네 문단, 녹음 85b05928-151.m4a 31.0초)
- "45번 ai 사진이 약간 이상해서 내가 다시 만들어왔어. 첨부한 사진(151)으로 바꿔줘." (2000x1116 사진)

1. 녹음 잇기(splice_v2.py -> rec/splice_v2.json)
   - 받아쓰기(rec/rec151_words.json): 바꿀 네 문단과 글자가 같음. '14일'은 두 곳 모두 '십사 일'로 읽음(v1 녹음은 '열나흘').
     음절 모델 점수로 확인(rec/which_word.py: '십사 일' -180.4 / -91.8, '열나흘' -272.7 / -184.9, 높을수록 맞음). 자막은 그대로 '14일'.
   - 자른 곳: 원래 녹음의 디지털 무음 속, 72.55초('정했습니다'와 '참가자들은' 사이)와 100.90초('떨어졌습니다'와 '그런데' 사이).
     새 녹음은 처음부터 끝까지 그대로 씀(꼬리를 자르지 않음, 끝 10ms만 줄여 이음매 잡음을 막음). 쉼은 앞 약 0.11초(원래 0.14초),
     뒤 약 0.44초(원래 0.39초).
   - 길이: 바뀐 구간 28.35초 -> 31.02초, 뒤는 모두 2.669초 밀림. 전체 410.03초, 영상 413.03초.
2. 음색과 크기 맞추기(rec/match_tone.py -> rec/match_tone.json)
   - 새 녹음은 앞뒤 원래 녹음(앞 40초, 뒤 30초)보다 낮은 소리가 약하고(160~315 Hz 약 -2.5 dB) 높은 소리가 강했음(8~12 kHz 약 +7 dB).
   - 1/3옥타브 차이를 고르게 만든 고정 EQ를 한 번 걸고(최대 ±6 dB, 맨 위 대역은 번짐을 막음), 크기를 앞뒤 녹음의 -14.3 LUFS에 맞춤.
     맞춘 뒤 차이: 80 Hz~12 kHz 대역 모두 ±2 dB 안, 12~16 kHz는 -2.9 dB(아주 작은 소리라 귀에는 거의 차이 없음).
   - EQ 필터의 지연(50ms)을 되돌려 새 녹음과 같은 시각에 맞춤(소리 위치 확인: 어긋남 0).
3. 자막 시각(run_align_v2.sh, merge_onsets_v2.py -> onsets_v2.json)
   - 이은 녹음으로 다시 맞춘 뒤 합침: 앞(V001~V051)은 v1 그대로(다시 맞춰도 차이 0), 새 녹음(V052~V070)은 새로 맞춘 시각,
     뒤(V071~)는 v1 시각 + 2.669초(다시 맞추면 3줄이 30ms 넘게 달라졌고, V071은 이은 자리 앞으로 당겨져 틀려서 v1 시각을 밀어 씀).
   - plan_sleep.py: V052, V067의 읽은 말을 '십사 일'로(자막 글자는 그대로).
4. 45번 사진: 새 사진(2000x1116)의 별 표시를 03편 2000 크기 별 모양으로 지움(투명도 0.49, wm_choose는 메움 선택).
   make_photos.py로 photos_final/P45.png. 상표나 글자 없음(휴대폰 화면의 시각만 보임).
5. 음악 경계(audio/bgm_segments.json)는 이은 자리 뒤 구간만 2.669초 밀림(같은 5곡). 마무리 곡은 끝이 영상 끝과 맞게 56.1초부터.
6. 장면 105개(사진 63, 스톡 42)는 v1과 같고, 이은 구간(사진 17~21, 20번 다시 씀) 뒤로 시각만 밀림.
