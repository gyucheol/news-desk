# 04편 「좋아하는 것」 부분 영상 v1 기록 (2026-11-02)

사용자가 보낸 대본(표시: 문장 뒤나 문장 사이의 숫자 = AI 사진 번호), AI 사진 50번까지(49장, 11번은 대본에 없음), 녹음 3개로
사진 50번 문장('B그룹의 아이들에게는 ~ 나중에 예상하지 못한 상을 줬습니다.')까지만 만든 영상의 기록입니다.
영상, 녹음, 사진, 스톡 원본, 음악 원본은 올리지 않았습니다.

요청(2026-11-02)
- "대본 전체 + 50번까지 사진 + 녹음본 전체 줄께. 지금 사진 50번까지밖에 생성 못해서 나머지는 내일 줄께. 일단 50번까지 ai 사진
  없는 건 스톡에서 영상 가져와서 사진 50번까지만 영상 만들어줘."
- "ai 사진을 쓰는 곳은 문장 뒤나 문장 사이에 숫자를 적어뒀음. ex) 그대를 만난건1 정말 행복이야2"
- "같은 숫자가 반복되는 건 똑같은 사진을 그 장면에도 쓰겠다는 뜻임"

파일과 순서(작업 폴더 scratchpad/ep4/v1에서)
1. photo_map.py: 받은 순서(in01~in49) -> 대본 번호. 사진 내용과 표시된 대사로 정함(메시지마다 5장, 1·2번째 메시지는 마지막 1장,
   3번째부터는 마지막 2장이 먼저 옴. 비커 두 장은 물 높이로 34번(같음)과 35번(FIXED가 낮음)을 구분).
2. 별 표시 지우기: 03편 도구(wm_remove_v3.py, wm_post.py, wm_choose.py)를 그대로, 03편의 별 투명도(2000, 1024 크기)를 씀.
   남은 자국: 7·13·39·40·42·45번은 wm_bh.py, 38번(책 모서리)은 wm_dir.py, 20번(니트 무늬)은 wm_patchfill.py.
3. make_photos.py: photos_final/PNN.png, 상표·로고 10곳 흐림(5, 6, 18, 19, 20, 21, 22, 25, 28, 30번).
4. 녹음: ../rec/part1~3.m4a. faster-whisper large-v3로 받아쓰고(part*_words.json), 대본과 다른 곳은 음절 모델(ctc_check.py)로
   다시 들어 녹음대로 자막을 씀(아래 '녹음과 대본').
5. join_narration.py: 1편 전체 + 쉼 0.20초 + 2편 0~44.20초 + 끝 무음 2초 -> rec.wav(자르거나 속도를 바꾸지 않음).
6. plan_data.py: 문장, 자막 조각, 자리(b 아래, c 가운데, i 가운데 기울임), 화면(P 사진, st 스톡). -> lines.json, units_disp.json
7. run_align.sh: align_words.py -> onsets.py -> ctc_align.py -> onsets_v2.py (03편 v2와 같은 도구) -> onsets_v2.json
8. build_segments.py -> segments.json(장면 66개: 사진 49, 스톡 17), build_spec.py -> spec.json
9. audio/bgm_segments.json: 배경음악 4곡(-36 LUFS, 곡마다 고정 크기), prep_audio.py(목소리 -14 LUFS), mix_audio.py
10. build_timeline.py, fit_clips.py, render_parallel.py(03편 v2 도구 그대로, render.py에 gain 패치 포함)

녹음과 대본(사용자가 보낸 대본과 다르게 읽힌 곳, 자막은 녹음대로)
- "그렇다고 시도해 본 게 없는 것도" -> 녹음 "시도해 본 적이 없는 것도"
- "정말 처음부터 자기 취향을 알고 있었을까요?" 다음에 녹음에만 있는 문장: "심리학 연구들을 살펴보면 좋아하는 마음을 어떻게
  바라보고 어떤 경험을 쌓느냐도 중요하다는 것을 알 수 있습니다." (표시 없음 -> 스톡)
- "인터넷에 직장인 취미 추천을 검색합니다.18" -> 녹음 "검색창에 직장인 취미 추천을 입력합니다." (사진 18)
- "그리고 한번 그려보자고 마음먹습니다. 23 / 그릴 사진을 찾은 다음 연필을 집어 듭니다. 24" -> 녹음은 한 문장
  "그리고 마음에 드는 그림을 보고 연필을 집어 듭니다." 앞부분에 23번, 뒷부분('연필을 집어 듭니다.')에 24번.
- "처음에는 길가의 꽃이 예뻐서" -> 녹음 "길가의 빛이 예뻐서" (두 인식 모두 '빛이')
- "그림을 그리는 일이 싫어진 걸까요" -> 녹음은 '쉬워진'으로 들림(whisper '쉬워진' 0.87, 음절 모델 '쉬어진'). 뜻이 바뀌므로
  자막은 대본대로 '싫어진', 다시 녹음을 제안함.
- 발음 차이만 있는 곳은 대본 글자(재밌을 -> 재미있을, 재밌어야 -> 재미있어야). whisper가 잘못 적은 곳(근거, 와 달리, 정말 좋아하는)은
  음절 모델로 대본과 같음을 확인.
